# 循记（Xunji）需求清单与范围冻结文档

> **项目定位**：面向 Java Web、数据库原理及软件体系结构分析三门课程的综合实战项目  
> **开发模式**：单人全栈开发  
> **预计周期**：3–4 周  
> **立项日期**：2026-11-20  
> **文档状态**：v1.0（范围已冻结，变更需在 `dev-log.md` 中记录）

---

## 1. 项目目标与业务闭环

本项目旨在构建一个轻量、完整、具备明显架构层次的个人学习辅助平台，围绕**学习闭环**展开，而非孤立功能堆砌：

```text
知识输入（笔记中心） ──► 计划与复习（日程中心） ──► 专注执行（番茄钟） ──► 反馈与治理（数据看板 + 管理后台）
          ▲                                                                              │
          └────────────────────── AI 学习助手（贯穿摘要 / 问答 / 智能建日程） ◄────────────┘
```

## 2. 技术栈选型（已定稿）

| 层级 | 技术选型 | 核心定位与课程对应点 |
| :--- | :--- | :--- |
| **后端框架** | Java 17/21 + Spring Boot 3.x + Spring Web | RESTful API、统一响应、全局异常、参数校验、AOP、定时任务 |
| **权限与安全** | Spring Security（或 Sa-Token）+ JWT + Redis | RBAC 角色权限隔离、无状态认证、Token 注销黑名单/踢人下线 |
| **关系型数据库** | MySQL 8.0 + MyBatis-Plus | 核心业务持久化、3NF 建模、事务控制、`FULLTEXT` 全文索引、SQL 优化 |
| **非关系型缓存** | Redis（NoSQL 内存数据库） | 认证态/黑名单、热点笔记与看板缓存（Cache-Aside）、AI 接口限流、延迟提醒队列 |
| **AI 能力接入** | Spring AI（或 OpenAI 兼容协议封装）+ SSE | 策略/适配器模式解耦大模型厂商（DeepSeek / 通义千问等）、流式输出 |
| **第三方服务** | Spring Mail（SMTP 邮件）+ 本地存储（可选 MinIO） | 临期日程邮件提醒、笔记插图存储 |
| **前端框架** | Vue 3 + Vite + Pinia + Vue Router + Element Plus | 前后端分离 SPA、路由权限守卫、组件化开发 |
| **前端核心组件** | `md-editor-v3` / `FullCalendar` / `ECharts` | Markdown 编辑器、交互式日历视图、学习数据可视化看板 |
| **接口与部署** | Knife4j (OpenAPI 3) + Docker Compose | 在线接口文档、容器化一键编排（兼作架构部署视图素材） |

## 3. 功能需求清单（按优先级冻结）

### 3.1 P0 核心必备（第 1–2 周完成：构建可演示保底闭环）

- [ ] **M1 认证与基础权限**
  - [ ] 用户注册、登录、退出登录（密码采用 BCrypt 加盐哈希存储）。
  - [ ] 基于 JWT + Redis 的登录态管理与注销失效控制。
  - [ ] RBAC 基础模型：区分普通用户（`USER`）与管理员（`ADMIN`），前后端双重路由/接口权限拦截。
  - [ ] 个人中心：修改昵称、头像、绑定邮箱（用于日程提醒）、修改密码。

- [ ] **M2 笔记中心**
  - [ ] 笔记本管理：单层分类增删改查、排序与笔记数量统计。
  - [ ] Markdown 笔记管理：集成 `md-editor-v3`，支持新建、编辑、实时预览、置顶、收藏。
  - [ ] 多标签管理：标签 CRUD，支持笔记与标签的多对多绑定与按标签筛选。
  - [ ] 全文检索：基于 MySQL `FULLTEXT` 索引实现按标题与正文关键词检索。
  - [ ] 回收站机制：基于逻辑删除支持移入回收站、一键恢复、彻底物理删除。
  - [ ] Markdown 导入导出：支持 `.md` 文件导入生成笔记及单篇导出。

- [ ] **M3 日程中心**
  - [ ] 日程 CRUD：标题、描述、开始/结束时间、提醒时间、优先级（重要/紧急）、完成状态。
  - [ ] 多视图展示：接入 `FullCalendar` 实现月/周/日视图，补充“今日待办”与“四象限”筛选视图。
  - [ ] **笔记 ↔ 日程双向关联**：日程支持绑定具体笔记，点击日程可直接跳转复习；笔记详情页可查看关联的复习日程。
  - [ ] **艾宾浩斯一键生成复习计划**：在任意笔记页点击触发，后端事务批量生成 `1/2/4/7/15` 天后的 5 条关联复习日程。

### 3.2 P1 进阶亮点（第 3 周完成：拉开课程与架构深度）

- [ ] **M4 AI 学习助手**
  - [ ] 统一 AI 适配层：基于策略/适配器模式抽象 `AiProvider`，支持通过配置切换不同大模型接口，并具备超时与降级兜底。
  - [ ] 笔记智能摘要与标签推荐：一键总结当前笔记要点并推荐 3~5 个标签（摘要持久化至笔记表）。
  - [ ] 单篇笔记流式问答（SSE）：将当前笔记内容注入上下文，实现打字机式流式问答，并记录对话日志。
  - [ ] 自然语言建日程：用户输入一句话（如“周五晚上八点前交体系结构报告，很重要”），AI 返回标准 JSON，前端回填表单确认入库。
  - [ ] Redis 接口限流：基于自定义注解 + Redis 对 AI 接口实施按用户频次/每日配额限流。

- [ ] **M5 番茄钟专注模块（已确认保留）**
  - [ ] 专注计时器：支持默认 25 分钟番茄钟及自定义专注/休息时长，支持开始、暂停、提前结束/放弃。
  - [ ] 业务绑定：启动专注时可选关联某篇笔记或某条日程。
  - [ ] 专注流水落库：完成专注后写入 `focus_record` 表（记录起止时间、实际专注分钟数、关联对象），并支持查看历史专注记录。

- [ ] **M6 定时提醒与缓存加速**
  - [ ] 临期日程提醒：基于 `@Scheduled`（可选结合 Redis `ZSet`）定时扫描临期未提醒日程，发送 `Spring Mail` 邮件提醒并生成站内通知。
  - [ ] Redis 缓存落地：对热点笔记详情、首页统计看板数据实施 **Cache-Aside** 缓存读写与更新失效策略。

- [ ] **M7 首页学习数据看板**
  - [ ] 集成 `ECharts` 展示：
    - 近 90 天学习活跃度热力图（综合笔记、日程完成、番茄钟记录）；
    - 日程按期完成率与本周趋势图；
    - 各笔记本/标签的笔记占比分布；
    - 每日/每周番茄钟累计专注时长统计。

- [ ] **M8 管理员治理后台（`ADMIN` 专属）**
  - [ ] 用户与角色管理：用户分页检索、禁用/启用账号、修改角色、强制踢人下线（清除 Redis 认证态）。
  - [ ] AI 用量与限流监控：查看全站/各用户 AI 调用次数与耗时统计，调整默认限流阈值。
  - [ ] 系统审计日志：基于 **Spring AOP 自定义注解**自动记录登录、删除、角色变更、AI 调用等关键操作并支持分页检索。

### 3.3 P2 后期可选拓展（第 4 周有余力时按需实现）

- [ ] **O1 笔记历史版本快照（已确认列为后期可选）**
  - [ ] 新增 `note_history` 表，记录每次显式保存或大幅改动时的快照（保留最近 5~10 个版本）。
  - [ ] 支持查看历史版本列表、文本差异对比（前端 Diff 展示）及一键回滚至指定版本。
- [ ] **O2 笔记插图对象存储升级**
  - [ ] P0/P1 默认采用本地磁盘目录映射；有余力时通过 Docker 部署 `MinIO` 并通过统一存储接口平滑切换。
- [ ] **O3 简单周期性日程**
  - [ ] 支持按天/按周重复规则，创建时自动展开生成未来 N 次日程实例。

### 3.4 Out-of-Scope（明确不做，范围红线）

> 以下功能**严禁**在本期开发中临时加入，仅在软件体系结构分析报告中作为“系统边界说明”或“未来架构演进方向”讨论：

- ❌ 多人实时协同编辑（OT / CRDT）
- ❌ 社区广场、公开帖子、点赞评论、好友关注体系
- ❌ 网课视频流媒体播放与大文件分片网盘
- ❌ 全库向量数据库 RAG 检索增强生成（本期使用单篇上下文 + MySQL 全文检索替代）
- ❌ 第三方日历（Google / Apple CalDAV）双向同步
- ❌ 微服务拆分（本期坚定采用**分层模块化单体 Modular Monolith**）

## 5. 课程交付物对应清单

- **Java Web 课程**：完整可运行的前后端分离系统源码、Knife4j 接口文档、权限拦截/AOP/SSE/定时邮件演示。
- **数据库课程**：E-R 图、建表 DDL、第三范式与适度反范式说明、事务控制示例、万级数据 `EXPLAIN` 索引优化对比、MySQL+Redis 缓存一致性说明。
- **软件体系结构分析课程**：
  - 架构风格选型与权衡决策记录（ADR：为何选择模块化单体而非微服务）；
  - C4 模型（Context / Container / Component）与 Docker 物理部署视图；
  - 核心场景时序图（JWT+Redis 鉴权、Cache-Aside 读写、AI SSE 流式问答）；
  - 质量属性战术分析（安全性、可用性/容错、可修改性、性能）。
